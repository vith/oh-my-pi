# Tool Permission System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace omp's approval subsystem with a single unified permission engine: deny-by-default posture, layered rule files (dynamic/project/user/curated), per-piece bash command evaluation via a real shell parser, an approval dialog with rule candidates and LLM suggestions, subagent park-and-bubble approvals, an audit log, and a `/permissions` management surface.

**Architecture:** A self-contained engine in `packages/coding-agent/src/tools/permissions/` replaces `resolveApproval` in the wrapper gate and the `BashTool.approval` function. Rule files (`permissions.yml` layers) + legacy settings keys feed one decision pipeline (deny absolute → first-match rules → posture). Bash commands are parsed with the vendored brush parser exposed through a new `parseShellCommand` pi-natives binding; compounds split into pieces evaluated independently — if all pieces pass, the original command executes unchanged. Headless pending approvals park on a promise and bubble a notice to the root session, answered in the focused subagent view.

**Tech Stack:** TypeScript/Bun monorepo, `bun:test`, Rust `pi-natives` (napi-rs + brush-parser 0.3.0), YAML (the `yaml` package already used by `settings.ts`).

**Spec:** `docs/superpowers/specs/2026-08-10-tool-permissions-design.md` (in this repo, committed on this branch) — the plan argues from the spec; executors read both.

- Engine decision precedence (from spec §3.1, fixed for the whole plan):
  1. tool-declared deny → `deny`
  2. legacy user-policy deny (`tools.approval.<tool>: deny`) → `deny`
  3. curated deny rules (CRITICAL_BASH_PATTERNS for bash) → `deny`
  4. rule `deny` (any layer, layer order: legacy bash patterns → dynamic → project → user) → `deny`
  5. tool-declared `prompt`/`override: true` → `prompt`
  6. legacy user-policy `prompt` → `prompt`
  7. legacy user-policy `allow` → `allow`
  8. first-match non-deny rule (legacy bash patterns → dynamic → project → user) → its action
  9. curated read-only allowlist (tool name in `CURATED_ALLOW_TOOLS`) → `allow`
  10. posture (`permissions.default`; else mapped `tools.approvalMode`: `yolo`→`allow`, `write`/`always-ask`→`prompt`; default `prompt`) → posture
- Rule YAML shape (from spec §3.2): `{ id?, tool: string|"*", match: { command|path|pattern: glob-or-/regex/, [argKey]: value|glob|regex }, action: allow|deny|prompt, reason?, ttl? }`. Globs support `*` only (converter identical to `bashApprovalPatternToRegExp` semantics); a string wrapped in `/…/` is a regex. `id` unique per file; invalid files skipped with a warning.
- Bash splitting semantics (spec §4): top-level `;`, newline, `&&`, `||`, `&` → pieces with operators; pipelines stay whole; nested constructs analyzed in-piece; any piece denied → whole call denied; all pieces allowed → execute original unchanged; PTY calls get whole-command analysis.

```rust
//! Parse shell command strings with the vendored brush parser and emit a
//! compact JSON node list.
use brush_parser::ast::*;
use brush_parser::{Parser, ParserOptions, SourceInfo};
use serde_json::{Value, json};

pub fn parse_script(command: &str) -> Result<Program, brush_parser::ParseError> {
    let options = ParserOptions::default();
    let source_info = SourceInfo::default();
    let reader = std::io::Cursor::new(command.as_bytes());
    let mut parser = Parser::new(reader, &options, &source_info);
    parser.parse_program()
}

pub fn parse_script_json(command: &str) -> Result<String, brush_parser::ParseError> {
    let program = parse_script(command)?;
    let nodes: Vec<Value> = program.complete_commands.iter().flat_map(|cc| cc.0.iter()).map(item_node).collect();
    Ok(serde_json::to_string(&nodes).expect("JSON serialization cannot fail"))
}

fn item_node(item: &CompoundListItem) -> Value {
    let (operator, children) = and_or_node(&item.0);
    let mut v = json!({ "kind": "sequence", "text": item.to_string(), "operator": operator, "children": children });
    // Single pipeline without additional and/or: flatten to the pipeline node itself.
    if item.0.additional.is_empty() {
        let pipe = pipeline_node(&item.0.first);
        v = json!({ "kind": pipe["kind"], "text": item.to_string(), "operator": operator, "children": pipe["children"] });
        if let Some(words) = pipe.get("words") { v["words"] = words.clone(); }
        if let Some(redirects) = pipe.get("redirects") { v["redirects"] = redirects.clone(); }
    }
    v
}

fn and_or_node(list: &AndOrList) -> (Value, Vec<Value>) {
    let mut children = vec![pipeline_node(&list.first)];
    let mut ops: Vec<&str> = Vec::new();
    for extra in &list.additional {
        let (op, pipe) = match extra { AndOr::And(p) => ("and", p), AndOr::Or(p) => ("or", p) };
        ops.push(op);
        children.push(pipeline_node(pipe));
    }
    (json!(ops), children)
}

fn pipeline_node(pipeline: &Pipeline) -> Value {
    if pipeline.seq.len() == 1 {
        return command_node(&pipeline.seq[0]);
    }
    json!({
        "kind": "pipeline",
        "text": pipeline.to_string(),
        "operator": "|",
        "children": pipeline.seq.iter().map(command_node).collect::<Vec<_>>(),
    })
}

fn command_node(cmd: &Command) -> Value {
    match cmd {
        Command::Simple(simple) => {
            let mut words: Vec<String> = Vec::new();
            let mut redirects: Vec<String> = Vec::new();
            if let Some(prefix) = &simple.prefix { for item in &prefix.0 {
                match item { CommandPrefixOrSuffixItem::Word(w) => words.push(w.value.clone()),
                    CommandPrefixOrSuffixItem::IoRedirect(r) => redirects.push(r.to_string()), _ => {} } } }
            if let Some(w) = &simple.word_or_name { words.push(w.value.clone()); }
            if let Some(suffix) = &simple.suffix { for item in &suffix.0 {
                match item { CommandPrefixOrSuffixItem::Word(w) => words.push(w.value.clone()),
                    CommandPrefixOrSuffixItem::IoRedirect(r) => redirects.push(r.to_string()), _ => {} } } }
            json!({ "kind": "simpleCommand", "text": simple.to_string(), "words": words, "redirects": redirects, "children": [] })
        }
        Command::Compound(compound, _redirects) => {
            let kind = match compound { CompoundCommand::IfClause(_) => "ifClause", CompoundCommand::WhileClause(_) => "whileClause",
                CompoundCommand::UntilClause(_) => "untilClause", CompoundCommand::ForClause(_) => "forClause",
                CompoundCommand::CaseClause(_) => "caseClause", CompoundCommand::BraceGroup(_) => "braceGroup",
                CompoundCommand::Subshell(_) => "subshell", CompoundCommand::Arithmetic(_) => "arithmetic",
                CompoundCommand::ArithmeticForClause(_) => "arithmeticForClause" };
            json!({ "kind": kind, "text": compound.to_string(), "children": [] })
        }
        Command::Function(_) => json!({ "kind": "functionDefinition", "text": cmd.to_string(), "children": [] }),
        Command::ExtendedTest(_) => json!({ "kind": "extendedTest", "text": cmd.to_string(), "children": [] }),
    }
}
```

```ts
import { parseShellCommand } from "@oh-my-pi/pi-natives";

export interface ShellPiece { text: string; operator: ";" | "&&" | "||" | "&" | null; }
export type ParseOutcome = { ok: true; pieces: ShellPiece[] } | { ok: false; error: string };

interface RawNode { kind: string; text?: string; operator?: string; words?: string[]; children?: RawNode[]; }

export function parseCommand(command: string): ParseOutcome {
	if (command.trim().length === 0) return { ok: true, pieces: [] };
	try {
		const nodes = JSON.parse(parseShellCommand(command)) as RawNode[];
		return { ok: true, pieces: splitIntoPieces(nodes) };
	} catch (err) {
		return { ok: false, error: err instanceof Error ? err.message : String(err) };
	}
}

export function splitIntoPieces(nodes: RawNode[]): ShellPiece[] {
	const pieces: ShellPiece[] = [];
	const push = (text: string | undefined, operator: ShellPiece["operator"]) => {
		const t = text?.trim();
		if (t) pieces.push({ text: t, operator });
	};
	for (const node of nodes) {
		if (node.kind === "sequence") {
			const children = node.children ?? [];
			for (let i = 0; i < children.length; i++) {
				const child = children[i];
				if (child.kind === "and" || child.kind === "or") {
					// children of and/or are pipelines: one piece per pipeline
					const pipes = child.children ?? [];
					for (let j = 0; j < pipes.length; j++) {
						const pipe = pipes[j];
						push(pipe.text ?? pipeText(pipe), j === 0 ? previousOperator(node, i, j) : child.kind === "and" ? "&&" : "||");
					}
				} else {
					push(child.text ?? pipeText(child), i === 0 ? previousOperator(node, i, 0) : node.operator === "&" ? "&" : ";");
				}
			}
		} else {
			push(node.text, null);
		}
	}
	return pieces;
}

function previousOperator(seq: RawNode, childIndex: number, pipeIndex: number): ShellPiece["operator"] {
	if (childIndex > 0) return seq.operator === "&" ? "&" : ";";
	return pipeIndex > 0 ? null : null; // first piece of first child: no operator
}

function pipeText(node: RawNode): string {
	return node.children?.[0]?.text ?? node.text ?? "";
}
```
