## Attributed original description

## What

Restore mouse-wheel scrolling while `tui.mouse` click-to-focus remains enabled. Route captured wheel-up into the existing transcript scroll view by rows, keeping the composer pinned below. Wheel-down to the live tail restores the normal screen and click-to-focus; typing returns to the preserved draft without submitting it. Ctrl+Up/Down retain prompt-hop behavior.

Reuse the existing Composer/TranscriptScrollView rather than adding a separate scrollback implementation. Update the setting description and mouse/navigation documentation.

## Why

With click-to-focus enabled, Herdr forwards wheel events to omp, but the main-session mouse handler consumed them without scrolling. Disabling click-to-focus was only a workaround, not a fix. This preserves both scrolling and click-to-focus.
